# 🔀 Guia de Workflow Git - Manter Fork Atualizado

Este guia explica como manter seu fork atualizado com o repositório original, mantendo suas modificações separadas.

## 📋 Estrutura de Remotes

```
upstream  → Repositório original (rakheOmar/Markdrop)
origin    → Seu fork no GitHub (seu-usuario/Markdrop)
```

## 🚀 Configuração Inicial

### 1. Renomear o remote original para `upstream`

```bash
git remote rename origin upstream
```

### 2. Criar seu próprio fork no GitHub

1. Acesse https://github.com/rakheOmar/Markdrop
2. Clique em **"Fork"** no canto superior direito
3. Isso criará uma cópia em `seu-usuario/Markdrop`

### 3. Adicionar seu fork como `origin`

```bash
git remote add origin https://github.com/SEU-USUARIO/Markdrop.git
```

Substitua `SEU-USUARIO` pelo seu nome de usuário do GitHub.

### 4. Verificar configuração

```bash
git remote -v
```

Deve mostrar:
```
origin    https://github.com/SEU-USUARIO/Markdrop.git (fetch)
origin    https://github.com/SEU-USUARIO/Markdrop.git (push)
upstream  https://github.com/rakheOmar/Markdrop.git (fetch)
upstream  https://github.com/rakheOmar/Markdrop.git (push)
```

## 🌿 Estratégia de Branches

### Branches Recomendadas

- `main` - Mantém a versão original limpa (sincronizada com upstream)
- `custom` - Suas modificações personalizadas
- `feature/nome-da-feature` - Features específicas

## 📝 Workflow Diário

### Receber Atualizações do Repositório Original

```bash
# 1. Garantir que está na branch main
git checkout main

# 2. Buscar atualizações do upstream
git fetch upstream

# 3. Mesclar as atualizações na sua main
git merge upstream/main

# 4. Enviar para seu fork (opcional)
git push origin main
```

### Trabalhar com Suas Modificações

```bash
# 1. Criar/alternar para branch de customizações
git checkout -b custom

# 2. Fazer suas modificações
# ... editar arquivos ...

# 3. Commitar suas mudanças
git add .
git commit -m "feat: minhas customizações"

# 4. Enviar para seu fork
git push origin custom
```

### Mesclar Atualizações com Suas Modificações

```bash
# 1. Atualizar main com upstream
git checkout main
git fetch upstream
git merge upstream/main

# 2. Voltar para sua branch custom
git checkout custom

# 3. Mesclar atualizações da main
git merge main

# 4. Resolver conflitos se houver
# ... resolver conflitos manualmente ...

# 5. Commitar a mesclagem
git commit -m "merge: atualizar com upstream/main"

# 6. Enviar para seu fork
git push origin custom
```

## 🔄 Scripts Úteis

### Atualizar do Upstream (Script Rápido)

Crie um arquivo `update-from-upstream.sh`:

```bash
#!/bin/bash
git checkout main
git fetch upstream
git merge upstream/main
git push origin main
echo "✅ Main atualizada com sucesso!"
```

Torne executável:
```bash
chmod +x update-from-upstream.sh
```

Execute:
```bash
./update-from-upstream.sh
```

## ⚠️ Boas Práticas

1. **Nunca commite na branch `main` diretamente**
   - Use `main` apenas para sincronizar com upstream
   - Faça todas as modificações em branches separadas

2. **Mantenha commits organizados**
   - Commits pequenos e focados
   - Mensagens descritivas

3. **Faça backup regular**
   - Push frequente para seu fork
   - Evita perder trabalho

4. **Documente suas modificações**
   - Mantenha um arquivo `CUSTOMIZACOES.md` listando suas mudanças

